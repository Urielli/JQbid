## 三步试用（Windows 10/11 x64）

1. 解压 zip 到**本地磁盘**（路径不要含空格；不要在压缩包内直接双击）
2. 双击 **启动.bat** —— 自动拉起 MySQL 与后端（首次运行会初始化数据目录，约 1–2 分钟）
3. 浏览器打开 <http://localhost:8080/>

首次使用**必须手动配置两组 API**（安装包不含任何 key，不配置则解析/生成功能不可用）：启动后打开 Web UI 的「模型服务配置」页，分别填入 **LLM API** key（如 DeepSeek，用于解析、生成、审校）与**生图 API** key（用于配图生成）。key 只保存在你本机，不回传、不上传。

停止：双击 **停止.bat**。卸载：直接删除文件夹，所有数据均在文件夹内。

## 常见问题

- **启动卡在 MySQL**：若你机器上装有其它 MySQL 服务占用了 3306 端口，启动脚本会明确报错提示——请先在 `services.msc` 停掉该服务再重试
- **后端没起来**：看解压目录下的 `backend.log`，错误原因一目了然
- **8080 被占用**：释放端口或修改配置后重试
